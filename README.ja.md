# 有限幅のAlcubierre形状に対するEulerian潮汐制約とエネルギーの一次補正

[English](README.md)

指定したAlcubierre計量で、単調なC²の半径方向形状が両端で内外の定数領域に滑らかにつながるクラスに限り、有限幅の壁に許す潮汐の上限を大きくすると、負のEulerianエネルギーの大きさの下限は調和形状の値に近づく。この論文では、その近づき方の一次係数を求めた。

\[
\eta\left[J_R^*(\eta)-\frac{R}{R-1}\right]
\longrightarrow \frac{1}{3R(R-1)^3}
\quad\text{（}R\in[3/2,3]\text{について一様）}.
\]

[論文（9ページ）](paper.pdf)、[LaTeX原稿](paper.tex)、[主張の一覧](claims.json)を収録する。**v1.2**は2026年10月27日に整えた公開候補で、公開リリースとDOIは未発行。repo名の案は **`alcubierre-tidal-energy-asymptotics`**。

## 対象と結果

内半径は1、外半径はRで、壁の幅R−1は1/2から2の間に保つ。形状関数は全体でC²かつ単調で、内外の定数領域へ正確につながる。定常計量のシフトは1成分、速度はv=1/10に固定する。制約は、Eulerian法線に対する**完全なRiemannテンソルの電気部分Eについて、E/v²のユークリッド作用素ノルムを全半径・全角度で抑える**もの。

無次元の指標はJ=∫₁ᴿ r²f′(r)² drで、指定速度での負のEulerian空間積分は−J/1200となる。定理1はη≥128での許容形状の存在、有限ηの明示的な下界、一様な誤差評価を与える。具体的定数は **η₀=128、B₋=5、B₊=61000**。上界は構成した許容族から得ており、最適形状の存在は仮定しない。誤差定数は粗い上界で、収束率の最適性は主張しない。

## 確かめた範囲

一様定理の根拠は本文の解析的証明である。有限計算は式と具体例の照合であり、無限のパラメータ範囲の定理を計算だけで証明するものではない。保存した記号計算では、Christoffel記号から潮汐テンソルを導き、ADM式と照合した。別方式の数値積分でも18組の質量・エネルギー積分を確認した。

**LeanはL1（主張文のみ）**。付属ファイルは、誤差定数を存在量化した、定理1より弱い帰結を記述する。以前の型検査は成功しているが、証明項はなく、具体的定数5・61000や計量から行列への導出も形式化していない。ファイルは以前と同一であり、今回再実行した記録ではない。AIによる点検は受けているが、**人間の専門家による査読は未実施**。[検証記録](VERIFICATION-RECORD.md)に根拠と限界をまとめた。

結果の範囲は指定した計量・半径方向の形状クラス・観測者・電気部分のノルムに限る。他の曲率成分や観測者の測定値、物質としての実現可能性、量子不等式、安定性、エネルギー条件の成立は結論しない。網羅的な新規性や優先権も主張しない。
